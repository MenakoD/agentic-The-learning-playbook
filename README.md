# Agentic — The Learning Playbook

**Build with agents. Understand how they work. Turn small projects into lasting skills.**

An interactive learning roadmap that explains agentic coding through four practical phases. Built with Remotion and designed as a responsive webpage for GitHub Pages.

## The four learning phases

1. **Master your tools** — Learn to guide a coding agent with clear goals, focused context, and small, useful projects.
2. **Understand the agent loop** — Explore how models use tools, observe results, and improve through feedback.
3. **Connect the workflow** — Bring working modules together using orchestration, validated information, and human approval.
4. **Engineer for trust** — Build habits around meaningful tests, code review, version history, and continuous improvement.

The suggested timings are flexible. Progress when you understand what you have built.

## Features

- Animated explainer powered by Remotion
- British English **Ryan** narration
- Synchronized captions and readable transcripts
- Chapter buttons for jumping to each learning phase
- Side navigation on desktop and compact navigation on mobile
- Dark design with purple, mint, amber, and pink accents
- Practical Air Cargo learning examples
- Links to supporting courses, articles, and documentation
- Reduced-motion support

## View the playbook

Open the repository’s GitHub Pages website and select **Watch the explainer**, or explore each phase at your own pace.

You can also download `index.html` and open it directly in a modern browser.

## Publish with GitHub Pages

1. Upload `index.html` to the root of this repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose your branch and the **/ (root)** folder, then select **Save**.

GitHub will display the website address when deployment is ready.

The page’s scripts, styles, narration, and captions are embedded in `index.html`. Google Fonts are optional; system fonts provide a fallback.
